# Следующая TestFlight-сборка

Сборка `1.0.2 (5)` продолжает работать с обновлённым backend: вход с кириллическим доменом и серверные исправления push не требуют новой сборки. Новая сборка нужна для исправлений звонков на iPhone.

## Что вошло в код для следующей сборки

1. Вход: email отправляется после `trim()`, пароль — как введён; у полей отключены автоисправление и заглавная буква, заданы `textContentType` для автозаполнения.
2. CallKit-звонок закрывается сам, если звонок оборвался в приложении: принятие не удалось (звонящий успел отменить, нет сети, нет микрофона), собеседник пропал из канала, соединение упало. Раньше системный экран оставался «идущим».
3. Разрешение на микрофон запрашивается сразу после входа: при ответе с заблокированного экрана iOS не может показать запрос, и собеседник не слышал бы пользователя. Текст `NSMicrophoneUsageDescription` теперь упоминает звонки.
4. Нативный PushKit сообщает в CallKit о каждом VoIP-push, в том числе о повторном или без данных звонка, — иначе iOS завершает приложение.
5. Отмена звонка через фоновый push не отправляет на сервер лишний `reject`; таймаут без ответа на iPhone записывается как пропущенный звонок, а не отклонённый.
6. После ответа через CallKit звук идёт в слуховой динамик, громкую связь включает пользователь.
7. Завершение и отклонение звонка больше не зависят от ответа сервера: экран и канал Agora сбрасываются сразу,
   а запрос на сервер при сбое сети повторяется в фоне. Раньше при ошибке (в логах 12.10 — 429) сервер не узнавал
   о завершении, у собеседника продолжало звонить, звонящий звонил снова — и собеседнику приходил второй входящий.
8. Сервер узнаёт о конце звонка и тогда, когда никто не ответил за 90 секунд, когда звонок сорвался у звонящего,
   когда собеседник пропал из канала или упало соединение. Таймер ожидания ответа сбрасывается при любом завершении
   и больше не может выключить следующий звонок.
9. Второй входящий во время другого звонка: на iPhone CallKit показывает его и сразу закрывает, на Android
   (приложение открыто) он не перекрывает текущий; сервер получает отказ, звонящий видит «отклонён».

Эти изменения касаются и Android: версию в Google Play (`caed20f`) тоже нужно пересобрать.

## Перед сборкой

1. `npx eas-cli whoami` — аккаунт с доступом к `@empin/empin-mobile`.
2. `npx tsc --noEmit`, `npx expo config --type public`, экспорт iOS-бандла с `IOS_WITHOUT_FIREBASE=true`.
3. `npx eas-cli build --platform ios --profile testflight`, затем отдельно `npx eas-cli submit --platform ios --profile testflight --id <EAS_BUILD_ID>`.

## Проверить на iPhone из TestFlight

- вход адресом с ASCII-доменом, `@эмпин.рф`, тем же адресом в Punycode, с пробелами по краям, с неверным паролем;
- входящий звонок: приложение открыто, свёрнуто, выгружено, экран заблокирован;
- ответ, отказ, отмена звонящим, завершение каждой стороной, двусторонний звук;
- отмена звонящим в момент ответа — системный экран должен закрыться;
- выход и повторный вход; вход тем же сотрудником на другом устройстве — старое перестаёт звонить.
